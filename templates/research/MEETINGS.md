# Meetings

One file for every meeting, across all projects. Mine; agents read it through the
`MEETINGS.md` link in each project and never write in it. Run `mtg` when a meeting
starts: it adds today's header and opens this file. Newest first. A few lines per
meeting: what was decided, what I owe, what they owe. When a meeting covers several
projects, start a line with the project name.
