# Meetings

This file holds notes for every meeting across all projects. Only you edit this file.
Agents read it through the `MEETINGS.md` link in each project and don't write to it.

When a meeting starts, run `mtg`. The command adds a header with today's date and opens
this file. When the meeting ends, run `mtg done` inside the project it concerned. Entries
are ordered newest first.

Write a few lines for each meeting:

- What was decided
- What you owe
- What they owe

If a meeting covers several projects, start each line with the project name.
